# TruthLens

Fake News Detection System using Python,
Natural Language Processing and Deep Learning.

## Technologies
- Python
- Pandas
- Scikit-learn
- TensorFlow
- Streamlit

## Project Objective
Detect potentially fake news using machine learning
and deep learning techniques, with a custom
Bahria University news dataset.
